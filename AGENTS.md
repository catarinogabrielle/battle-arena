# Regras do Projeto - Battle Arena: Last One Standing

## Fluxo de Git Obrigatório
- **Sempre que concluir alterações ou novas implementações no projeto, realize o commit das mudanças e dê push direto no repositório remoto na branch `main` (`git push origin main`).**
- Mantenha mensagens de commit claras e descritivas (ex: `feat: ...`, `fix: ...`, `refactor: ...`).
- Nunca deixe código gerado ou modificado sem sincronizar no GitHub na branch `main`.
